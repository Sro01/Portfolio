# 개인 포트폴리오

개인 포트폴리오 웹사이트입니다. 소개와 프로젝트, 경력 등을 공개하고, 별도 관리 화면에서 콘텐츠를 수정한 뒤 저장할 수 있습니다.

## 기능

### 공개 포트폴리오

- 자기소개와 프로필
- 프로젝트 목록과 상세 정보
- 경력, 기술 및 이력서 안내
- 연락처와 외부 링크
- 모바일과 데스크톱에 대응하는 반응형 화면

### 콘텐츠 관리

- 관리자 로그인 및 접근 권한 확인
- 별도 관리 화면에서 소개, 프로젝트, 경력 등의 추가·수정·삭제
- 저장 버튼으로 변경 내용을 서버 측 저장소에 영구 저장
- 저장 성공 시 공개 페이지에 변경 내용 반영
- 입력값 검증과 저장 상태 표시
- 저장 실패 시 입력 내용을 유지하고 재시도 안내

편집과 저장은 관리자에게만 허용하며, 방문자는 공개된 콘텐츠를 조회합니다.
